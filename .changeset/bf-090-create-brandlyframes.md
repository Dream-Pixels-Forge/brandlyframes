BF-090 — `create-brandlyframes` scaffold CLI + 5 project templates.

New users can run `npm create brandlyframes@latest` to scaffold a BrandlyFrames project from one of five curated templates:

- **blank** — minimal frame counter (hello world)
- **hello-world** — animated gradient circle with progress indicator
- **captions** — cycles through frame-driven captions using `useCurrentFrame` / `useVideoConfig`
- **product-promo** — multi-scene animated promo with per-scene styling and transitions
- **frame-video-demo** — frame-exact seek accuracy demo with time-anchor markers

Each template is a Vite + React project that scaffolds into a runnable dev server in under a minute.
